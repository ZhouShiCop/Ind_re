# Ind_re

Ind_re 是一个基于 Godot 4 的地图/建筑编辑实验项目。项目目前主要聚焦于**瓦片地图编辑**、**模式切换**与**相机操作**，适合作为一个简单的游戏原型或编辑器 demo。

## 项目简介

这个项目实现了一个带有基础工具栏的地图编辑流程：
- 可以在地图上进行**建造**与**删除**操作
- 支持连续绘制，避免逐个点击
- 提供选框/取消模式来辅助区域选择
- 使用自由相机进行地图浏览与缩放

## 主要功能

### 1. 地图编辑模式
- **Build_Mode**：在地图上放置瓦片
- **Destroy_Mode**：删除已有瓦片
- **Cancel_Mode**：只显示选区，不直接修改地图

### 2. 连续绘制
- 鼠标按住拖动时，会沿着路径持续处理瓦片
- 内部使用 Bresenham 直线算法，保证绘制路径平滑连贯

### 3. 相机控制
- 鼠标滚轮：缩放视图
- 中键拖拽：平移地图

### 4. 信号总线架构
- 项目通过全局 `SignalBus` 管理跨组件通信
- 便于 UI、地图逻辑、场景切换之间协作

## 项目结构

- `Secen/`：场景文件
  - `Main.tscn`：主菜单/入口场景
  - `Gaming.tscn`：游戏主场景
- `Script/`：脚本逻辑
  - `Component/`：地图逻辑、相机、按钮、信号总线等组件
  - `DataStr/`：数据结构定义
- `Res/`：资源与贴图
- `Texture/`：图像资源
- `addons/`：Godot 插件目录

## 开发环境

- Godot Engine：4.6
- 语言：GDScript
- 主要设计方向：地图编辑器 / 游戏原型

## 使用方法

1. 打开项目根目录中的 `project.godot`
2. 运行项目
3. 在主场景中进入地图编辑界面
4. 使用工具栏切换建造、删除、选框模式
5. 使用滚轮与中键控制地图视角
